# netflix-gpt 
# Purpose of the Application

The primary goal of this project is to revise and strengthen core ReactJS skills by building a practical, real-world application.
It helps reinforce important concepts such as:

Component-based architecture
React Router for navigation
State management using Redux Toolkit
Building and using custom hooks
Managing authentication flows
Testing React applications with Jest and React Testing Library
Integrating third-party APIs (GPT + TMDB)
This project serves as a hands-on learning and revision tool for modern React development best practices.


# Authentication (Firebase)

Sign In / Sign Up using Email & Password
Firebase onAuthStateChanged for session management
Automatic redirection after login/logout
User profile updates using updateProfile

# GPT + TMDB Movie Recommendation

Search movies by description
GPT generates movie suggestions
Custom hook fetches TMDB details
Results shown in category-based layout

# Routing (React Router DOM)

Protected routes
Public vs private route flow
Programmatic navigation with useNavigate()

# Redux Toolkit

Centralized global state
createSlice() for cleaner reducers
Manages user session, GPT search mode, movies

Custom Hooks

# Reusable hooks for:

GPT + TMDB movie fetching

API abstractions

# Testing

Jest for unit tests
React Testing Library for UI behavior
Firebase Auth mocking
Redux state mocking
Custom hook tests
